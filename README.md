# Daily Math Buddy — бот для тренеровки таблицы умножения 

Добро пожаловать в Daily Math Buddy — Telegram‑бота, который помогает выучить таблицу умножения 

Описание
-------

Бот присылает выбранные по сложности примеры как только вы ответили на прошлые и в конце дня присылает вам статистику, по которой вы можете отслеживать свой результат

- Когда вы хотите - бот вам присылает сообщения с примерами из таблицы умножения
- Отслеживание выполнения: точность, время решения, ежедневная активность.
- Ежедневная статистика и сводка достижений.
- Напоминания и лёгкая геймификация для постоянной мотивации (например, в виде лидер борда).

Как это работает
---
- Вы запускаете бота, вы выбираете сложность и он вам присылает пример
- Бот присылает вам сообщение и вы на него отвечаете
- Вы отмечаете выполнение (отправляете ответ), бот фиксирует результат.
- Вы можете посмотреть краткую статистику.

Команды
---
- `/start` — начать работу с ботом
- `/settings` — выбрать тему и частоту сообщений
- `/stats` — посмотреть текущую статистику
- `/export` — экспортировать результаты

Почему это полезно
---------------

Короткие регулярные сессии эффективнее длинных редких занятий. Этот бот создан, чтобы превратить практику в привычку и дать прозрачную метрику роста — вы увидите улучшение на графике.
